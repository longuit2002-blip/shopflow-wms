## Architecture Summary

**Verification-gate-driven sweep.** The Sprint-8.5 success criterion was a clean `dotnet build ShopFlow.sln` (0 errors + 0 warnings). Per-csproj CI already passed; the solution-level gate becomes meaningful only when every project compiles together. The sweep added **2 new PackageVersions to CPM** (Microsoft.Extensions.TimeProvider.Testing 9.0.0 + Microsoft.Extensions.Logging 10.0.7) + bumped one (Logging 9.0.0 → 10.0.7 to clear an NU1109 against Hosting 10.0.7's transitive floor).

**Latent errors surface in dependency chains.** The 10 errors weren't independently introduced; they were latent from Sprint-7.5 + Sprint-7 work that compiled in isolation but couldn't survive the full-solution graph once Sprint-8 U10's shopflow-migrate ProjectReference to Auth.Infrastructure transitively pulled the broken consumers into one tree. Sweeping them in one sprint stops the snowball.

**4 new `docs/solutions/` entries** captured during the sweep, not after sign-off. Patterns documented:
1. **Polly v8 PredicateBuilder generic-on-type vs lambda predicate** — when typed pipeline isn't possible (consumer ctor takes non-generic), hand-roll the predicate.
2. **`Microsoft.Extensions.TimeProvider.Testing 9.0.0`** — canonical .NET 9 FakeTimeProvider package; cross-references Sprint-5 U7 TimeProvider injection precedent.
3. **`SkuDimensions` using-directive discipline** — when a value object moves to a sub-namespace (Sprint-7.5 U3), every consumer needs an explicit using OR a fully-qualified path through the COMPLETE nested namespace.
4. **Cross-module contract evolution** — `git grep` consumer-test sweep before changing a `Contracts/*.cs` ctor; alias-vs-break decision matrix.

**Migrate.IntegrationTests as the third Testcontainers project.** Follows the Sprint-1-redux InventoryTenantFixture + Sprint-8 U3 AuthTenantFixture pattern. Provisions fresh tenant DBs per test class with both Inventory + Auth migrations applied — the OwnerSeed flow inserts into the `users` table, which requires the Auth migration; the fixture sequences them correctly. Establishes the pattern for any future shopflow-migrate integration coverage (provision happy-path, archive flow, etc.).

## Key Technical Decisions (KTDs) — final state

1. **KTD1 — StockSyncOptions: nested `QueueCapacity` → `QueueCapacitySettings`**. Property name unchanged; convention now consistent with `TokenBucketSettings`/`BreakerSettings`.
2. **KTD2 — Polly v8 PredicateBuilder lambda fallback for non-generic pipelines**. Documented in the solutions note + inline in the test.
3. **KTD3 — Microsoft.Extensions.TimeProvider.Testing 9.0.0** in CPM. Pinned at 9.0.0 (not 10.0.7) because Outbound.UnitTests doesn't transitively pull Hosting 10.0.7 — the lower floor works.
4. **KTD4 — Microsoft.Extensions.Logging 10.0.7** in CPM. Bumped from initial U1 pin of 9.0.0 to clear NU1109 against Hosting 10.0.7 (Aspire dep tree).
5. **KTD5 — Inventory.IntegrationTests BuildRepo uses tenant.BuildRequestContext()**. No fake RequestContext — keeps tests on the real-DB path.
6. **KTD6 — SkuDimensions fix is a using-directive change, not namespace consolidation**. Confirmed only ONE type exists; the duplicate-type appearance was a stale-FQN illusion.
7. **KTD7 — Outbound contract drift fixes update the consumer test, not the contract**. Current canonical shape preserved; Sprint-7 evolution was correct + the consumer test was simply behind.
8. **KTD8 — One commit per file group**, not per error. ~10-12 units; co-located errors landed together.
9. **KTD9 — docs/solutions/ notes co-located with their fix commits**. Institutional knowledge compounds at the point it surfaces, not in a separate end-of-sprint pass.
10. **KTD10 — Migrate.IntegrationTests is a new project**. Not a sub-suite of Auth.IntegrationTests — module ownership is cleaner.

Sprint-8.5 actual fix count = 12, not 10.
- **U5 lambda predicate, not typed-builder migration**. Plan KTD2 said "move generic from method to type." Research-confirmed that the `ShopeeAdapter` ctor takes the NON-generic `ResiliencePipeline`, so the typed builder doesn't compose. Hand-rolled the predicate as a `switch` expression on `args.Outcome`. Documented inline + in the solutions note as both shapes (typed builder for new pipelines, lambda for adapter-bound).
- **U9 + U10 ran in 2 commits, not 1**. Plan suggested co-locating R7+R8 (U9) and R10+R11 (U10). Honored.
- **All `docs/solutions/` entries landed alongside their fix commit**, not in U12. Plan KTD9 said this; honored.
- **No local Docker daemon on this dev machine** — same Sprint-1+ posture. Migrate.IntegrationTests built clean but execution deferred to CI.
